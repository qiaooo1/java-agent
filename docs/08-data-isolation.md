# 数据安全与用户隔离

当前隔离单位是已认证用户。资源没有可由客户端指定的 `tenantId`，也没有组织成员或跨用户共享模型；现有实现不等同于组织级多租户 RBAC。

## 身份边界

网关和平台各自验证 HS256 签名、发行者与时间有效性，并要求非空且长度受限的 `sub` 以及必需的 `exp`。缺少身份或过期字段的已签名令牌也被拒绝。正常登录签发的令牌兼容本次校验，时间有效性沿用 Spring Security 的默认时钟容差。`X-User-Id`、`X-Internal-User` 和请求体中的身份声明不能替代 JWT；用户标识始终取自验签结果。

平台使用无状态安全链；网关显式使用空的安全上下文仓储与请求缓存，不通过 Session 保存认证或恢复请求。带合法令牌的一次请求不会使后续不带令牌的 API 请求获得认证。

部署应在网关和平台配置相同的独立 `JWT_SECRET`，通过 HTTPS 传输。仓库保留的本机演示默认密钥不能用于公开部署。本次没有实现刷新令牌、即时吊销、密钥轮换或身份服务联邦接入。

## 数据访问边界

| 资源或动作 | 服务端约束 | 拒绝后的行为 |
|---|---|---|
| 任务详情、列表、分页游标 | SQL 限定 `user_id`；分页游标必须属于当前用户 | 跨用户标识与不存在标识均返回 404 |
| 取消任务、人工复核 | 锁定查询同时限定任务与当前用户，在原有事务中执行 | 不改变原任务、事件序号或额度 |
| 事件、执行尝试、进度、SSE | 每次读取校验任务所有者；订阅前鉴权，补读时再次校验 | 跨用户 SSE 不建立异步连接 |
| 知识列表与任务绑定 | 用户过滤列表；提交任务前校验文档所有者 | 绑定他人文档不创建任务或预留额度 |
| Worker 知识检索 | 工具实例固定用户与文档，片段查询 JOIN 文档表并再次限定用户 | 越权或文档不存在转成终止型 `PERMISSION_DENIED`，不回传原始异常 |
| 工作记忆状态 | 查询先校验任务所有者，再限定执行尝试；写入需当前有效执行凭证 | 查询仅返回元数据，失权、取消或旧序号写入被拒绝 |
| 幂等与额度 | 幂等键按用户唯一；额度从已验签用户查询 | 不同用户使用相同幂等键仍创建各自任务 |

知识检索文本限 2000 字符；格式错误返回可纠正的 `INVALID_ARGUMENT`。模型只能提供检索文本，附加的用户或文档参数不会改变实例绑定。该边界位于 Java 和 SQL 中，不依赖提示词要求模型遵守。

诊断证据当前来自共享的合成演示源，环境白名单不代表某个真实租户的资源授权。接入真实环境时还需建立服务端的用户/组织与资源目录映射。

## 对外数据与浏览器边界

用户侧任务接口使用 `TaskView` 字段白名单，包括任务标识、输入、状态、尝试次数、取消意图、结果/安全错误、账期、Trace、创建时间与事件水位。提交、幂等重试、列表、详情、取消以及工单提交使用同一转换；不直接序列化内部 `Task` 的所有字段。用户标识、幂等键、Agent 执行配置、Worker 地址、租约和最大重试配置不出现在这些任务响应中。Worker 内部的完整快照保持可用。

网关和平台均设置 CSP：脚本、样式和连接仅允许同源，禁止对象插件、外部 base 地址和页面嵌入，并设置 `Referrer-Policy: no-referrer`。沿用安全链的 `Cache-Control: no-store` 与 `nosniff`；前端令牌仍只存内存，动态结果仍按纯文本节点展示。

这些措施限制应用的数据访问与浏览器行为，不提供数据库管理员隔离、磁盘加密或通用的个人信息/密钥自动识别。用户授权文档片段和目标仍可能发送到配置的模型供应商；原始任务与证据事件仍按现有方式存储，仅对任务所有者开放。接入真实业务数据前需要另行确定供应商、数据留存、脱敏与加密策略。

## 验证入口

- `DataIsolationApiTest`：两个真实注册用户，经实际 JWT / Spring Security / H2 验证详情、事件、进度、尝试、SSE、取消、工单复核、知识绑定、分页、幂等、额度、响应字段和安全响应头；验证拒绝没有业务副作用。
- `KnowledgeIsolationTest`：使用正式 Flyway 迁移与真实 SQL，验证相同查询只返回选中的自有文档，跨用户和缺失文档一致拒绝，以及查询规模限制。
- `TaskKnowledgeToolTest`：经过真实工具注册表验证权限错误分类、异常消息不外泄，以及两个并行工具实例不交换绑定范围。
- `GatewayJwtTest`：真实 JWT 编解码与响应式安全过滤链，验证合法身份、缺失字段、过期、错误发行者/签名、匿名拒绝与响应头。

默认 `mvn -B -ntp verify` 执行上述测试。H2 与进程内 HTTP 安全链验证不等于 MySQL 锁行为、生产部署或真实模型安全评估。实际运行结果见[维护日志](maintenance-log.md)。
